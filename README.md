# Strand

Store work notes and pull them for interviews, resumes, reviews.

GitHub repo: `swe-knowledge-base`.

```bash
cp .env.example .env
npm install
npx prisma migrate dev
npm run db:seed
npm run dev
```

http://localhost:3000

Seed: `demo@strand.app` / `demo1234`

Optional: `OPENAI_API_KEY`. Without it, local heuristics still run.
